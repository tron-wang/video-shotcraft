时长: 约 8.3s（250f@30fps；四条新消息 f36/116/156/204，末条后 46f hold）
能量: 中低（节奏跟随真实对话，单个动作都很小，靠持续的"有人在回复"撑住注意力）

## 意图
聊天镜头的信息不在任何一个气泡里，而在"对话正在发生"这件事上。所以动作全部来自
真实 IM 的交互语言——正在输入、弹出、发送、上推——观众不用读完每条消息，也能读懂
"这里有人在协作"。

关键是**时序的可信度**：三点提示先于消息、自己的消息先打字再发送、滚动和新消息同帧。
这三条里任何一条错了，观众都会感到"这是做出来的动画"。

## 动效核心
- **挂载时一次排好版**：所有行（包括还没出现的）都在布局里占位、只是透明；
  `delayRender` 实测每行 `offsetTop / offsetHeight` 后再放行，测完之前整个列表透明
- **无状态滚动**：每条新消息产生事件 `{帧, 需要露出到的高度}`——对方消息在三点提示
  帧需要 `行顶 + 84px`（三点气泡高），在消息帧需要 `行底`。目标取历史最大值，
  `scroll = Σ (目标ₖ − 目标ₖ₋₁) × ease((f − 帧ₖ) / 12)`，`bezier(.25, 1, .5, 1)` 快起软落
- **气泡弹入** 10f：`scale .86 → 1`（`out(back 1.7)`）+ `translateY 14 → 0`，透明度
  只用前 5f；`transform-origin` 钉在头像侧上角（对方 left top、自己 right top），
  与该角 12px 的小圆角同侧
- **三点提示**：绝对定位在槽位顶端；三个点按 18f 周期 `max(0, sin)` 跳 8px、相位差
  0.18 周期，跳起时透明度 .45→1。消息到点时三点 3f 内缩到 .9 并淡出，**同帧**真气泡
  弹入——两者重叠，不是先后
- 头像跟三点提示一起出现，而不是跟消息：观众先知道"谁在打字"
- **自己的消息**：消息前 8f 输入框出现光标；0.29 字/帧（≈8.7 字/秒）逐字打出，打完
  光标按 16f 周期闪烁；发送前 3f 按键 scale 1→.84，消息帧清空输入框、气泡弹入、
  按键 10f 回弹。输入框有字时发送键实心、空时浅色
- **富卡片消息**：卡片整体用同一弹入语法；卡内进度条晚 4f 开始、18f 填满，
  "x/12 regions" 计数跟着进度走——次级动作让位主动作
- 整个窗口 8s 内极缓推近 1→1.035（`inOut(sin)`）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 弹入 | 10f，scale .86→1，back 1.7 | 起始 <.8 读作从远处飞来；back >2.2 气泡像果冻 |
| 弹入透明度 | 前 5f | 与缩放等长时要到过冲顶点才完全不透明，气泡发虚 |
| 三点提示时长 | 22–26f | <15f 看不清是"正在输入"；>40f 节奏拖沓 |
| 三点跳动 | 18f 周期、8px、相位差 .18 | 周期 <12f 读作焦虑闪烁；三点同相就是一起上下晃 |
| 打字速度 | 0.29 字/帧 | 真人速度（R3），观众能跟读；>0.6 字/帧读作粘贴 |
| 发送按压 | 3f 压到 .84、10f 回弹 | 没有按压，气泡像自己冒出来的 |
| 滚动 | 12f，与新气泡同帧起步 | 晚于弹入时新气泡先在视口外弹一下；>20f 列表拖泥带水 |
| 对方消息间隔 | ≥40f | 更密读作刷屏，来不及读完上一条 |
| 正文字号 | 34px | Q11：≥32px 才在手机小窗里可读 |
| 末条后 hold | ≥40f | 末条通常是结论或情绪落点，要给读完的时间 |

## 已知坑
- 行高必须实测，不要按字数估：换行和字体回退都会改变行高，估错的滚动量会让最后一条
  消息被输入框盖住半截
- 三点提示挂在槽位**顶端**，不要挂行底：富卡片行比三点气泡高 170px，挂行底时三点
  上方会空出一大块
- 头像**顶对齐**：底对齐时头像会随多行消息/卡片的高度往下跑，三点提示阶段头像和
  三点气泡分离
- 滚动目标必须取历史最大值：三点提示阶段需要的高度比消息阶段小，直接用每个事件的
  需求值时列表会先上推再回落
- 卡内计数/进度要晚于卡片弹入开始；同帧开始时卡片还在 scale 过冲，进度条读不清
- 头像、名字、配色全部用占位（首字母 + 渐变），不要复刻某个真实 IM 的气泡造型和标志色
  （如绿色/蓝色气泡），避免暗示特定产品
- 消息文案要像真人：短句、有语气。"Hello, this is a message" 式占位会让整个镜头失去
  可信度（Q10）
- demo 文案刻意不用 emoji：无头 Linux 渲染环境可能缺彩色字形，渲出来是方框
