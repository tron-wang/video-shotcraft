## 意图
把「切页面」做成「在同一条滑轨上移动」：板块不是互不相干的 tab，而是排在一起的一列大卡。每次换面，镜头先拉远——观众瞬间看到左右邻居、知道自己在整体的哪一块——再平移到下一张、推近到读得清。空间连续性替代了硬切转场，又比 3D 转立方体（本卡旧版）干净现代。
（2026-09 改版：使用者从「横向滑轨 / 纵深堆叠 / 便当格总览 / 推页视差」四案里选了横向滑轨；卡名沿用。）

## 动效核心
- **版面**：卡宽高比 880:1180（直式大卡），卡宽 ≤ 画面宽 81.5%、卡高 ≤ 画面高 61.5%，垂直略高于中线；卡间距 = 卡宽 8%；圆角 = 卡宽 4%；1.5px 强调色 28% 描边
- **换面**：`moveFrames`（预设 26f）内一气呵成——位置用 `easeInOutCubic` 从第 i 张平移到第 i+1 张；同一段时间整列缩放按 `sin(π·t)` 从 1 拉到 `pullTo`（0.62）再推回 1，缩放原点在当前卡中心
- **邻居**：离当前卡越远越暗（亮度 1 → 0.55）；距离 > 2.2 张的不渲染
- **进度点**：卡下方一排点，当前那颗拉长成胶囊（12 → 44）并变强调色，跟着连续位置平滑过渡
- **预设版面**（给 `title` 等就会画）：深色渐层卡 + 右上金色光晕 + 编号（强调色）/ 130 大字标题 / 说明 / 三条信息条 / 底部强调线；给 `content` 则放自己的截图或 UI
- 以画幅比例排版，横式、直式都能用（横式画幅较宽，静止时就看得到左右邻居）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `panels` | 3–6 张 | > 6 张换面太多像翻相簿；2 张请改用推页或硬切 |
| `stepAt` | 各板块开讲的词锚帧 − 13 | 换面中点对在词上最顺；不给则平均分配 |
| `moveFrames` | 26（20–32） | < 20 拉远还没看清邻居就推回；> 32 像在找东西 |
| `pullTo` | 0.62 | 0.5 看到更多邻居（总览感强）、0.75 较含蓄 |
| `dots` | true | 板块 ≥ 3 时建议保留；画面下方另有字幕时确认不重叠 |
| `accent` | `theme.accent` | 编号、描边、进度点、底部线同色 |

## 已知坑
- **换面落在旁白句中**：拉远那一下会把视线拉走；`stepAt` 对在板块开讲的第一个词（或句间气口），不要压在上一段的重点词上
- **截图当 content**：卡是直式 880:1180，横式截图放进来只剩中间一段；横式素材请先裁好或改用 `page-anchor-tour`
- **邻居的内容会被看到**：拉远时左右邻居露出约 40%，下一张的标题会提前被瞄到——这是这张卡的用意（预告），若脚本要「揭晓」下一张就别用它
- **进度点与字幕**：直式画面进度点在卡下方约 y 1370；字幕在 y≈1480，间距够，但卡加高时要确认
