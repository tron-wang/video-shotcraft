## 意图
社群贴文的说服力来自"它长得就是一则贴文"：头像、帐号、认证勾、时间、互动数。把贴文放大到满版、用多段推近在里面巡游，观众只看到一堆被裁掉的字，反而认不出这是什么——使用者实片回馈就是"放太大、周边没有适当留白、效果太多"。这张卡让整则贴文**完整地站在画面中间**，四周留暗底；开场浮上来一次交代"这是一则贴文"，旁白念到重点时相机只轻推一下、画一笔，然后就安静下来让人读。完全静止又太死板，所以留下这两个动作：进场一次、重点一次。

## 动效核心
- **尺寸**：贴文宽 860（两侧各留 110），在 SAFE 区（y 150–1420）垂直置中；裁掉底部「閱讀 N 則回覆」按钮与留言，只留到互动数那一行（`pageH`）。760 使用者嫌太小，960 满版没有留白
- **A 立体浮入**（`enterAt` 起 18 帧、`outCubic`）：从下方 60px 浮上 + `rotateX` 8°→0 回正 + 阴影由浅（0 4 12 / 0.2）变深（0 14 40 / 0.5），不透明度 8 帧内淡入
- **B 跟着重点轻推**：每个 mark 的 `at − 10` 起 24 帧 `inOutCubic` 推到 `zoom`（预设 1.08）并往重点偏移 35%；多个 mark 依序从上一个状态过渡。偏移与倍率都夹在安全框内——推近后贴文**左右仍各留 ≥ 60、上 ≥ 130、下 ≤ 1440**（字幕 y≈1480），倍率超过会自动封顶（w 860 时约 1.09）
- 整镜另有 1.00→1.02 极缓推近，夹边时已算进去
- **记号**：`marker` = 强调色 multiply 荧光笔，10 帧由左往右扫出（一行内的短语）；`circle` = 与 `ink-circle-note` 同一支笔（`inkLoop` + 三层假笔压，按显示坐标 1.3 倍粗），14 帧画完一圈（一整句 / 一个标签）。圈画在贴文圆角框之外的同一层，可以略出贴文边、不被裁
- **清晰度**：贴文按画面实际尺寸排版（`Img` 宽 100% = 860，2× 原图直接缩下来），3D 变形只在浮入那 18 帧，之后换纯 2D `translate + scale`

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `post` | `<Img src={staticFile('social/<id>/post.png')} style={{ width: '100%', display: 'block' }} />` | 必须以容器宽排版；**不要**把 642 宽的版面再 `scale` 上去（3D 期间会糊） |
| `pageW` / `pageH` | 642 / 裁到互动数那一行 | 页面坐标 = post.png 像素 ÷ 2；`pageH` 以静帧确认按钮上缘的细线也裁掉 |
| `w` | 860 | 贴文很高（`pageH × w / pageW` > 1150）时降到 800，别让上下贴边 |
| `marks[].rect` | 页面坐标的字框 | 从 post.png 量（像素 ÷ 2）；圈的框比字身宽一点，荧光笔的框贴字 |
| `marks[].at` | `f(tWord(i, 重点词)) − from` | 相机提前 10 帧开始动，记号在词锚帧落下 |
| `marks[].kind` | 第一处 circle、第二处 marker，或两处同种 | 同一句话上不要叠两种记号 |
| `marks[].zoom` | 1.08 | 超过安全框会自动封顶；想更"推"就把 `w` 调小，不要放宽边界 |
| `enterAt` | 4 | 让镜界 10 帧擦除先开一截再浮上 |
| `ink` / `marker` | `#c8341f` / `theme.accent` | 白底贴文上用朱红圈、金色荧光笔 |

## 声音
浮入不配音（镜界擦除已有一记）。圈落笔可配 `text/marker-pen-line.mp3` 0.18–0.2，荧光笔不配；两处记号只配第一处。全部 ≤ 0.35。

## 已知坑
- **别放大到满版**：贴文宽 > 900 或推近后左右留白 < 60，就回到"周边没有适当留白"。要强调细节请用记号，不要用倍率
- **效果不要叠**：一镜最多 2 个记号，不加批注箭头、不做多段巡游（长页巡游是 `page-anchor-tour` 的事，单则社群贴文不要用它）
- **糊字**：3D 变形（`perspective` / `rotateX`）会让 Chrome 按排版尺寸点阵化整层再放大——所以版面必须用显示宽排版、3D 只在浮入期间。实测改完后同一格锐利度 +16%
- **底部按钮裁一半**：`pageH` 切在「閱讀 N 則回覆」按钮上缘时，会留一条圆角框的细线；往上再收 15–20px
- **工作台预览偏软**：播放器把 1080×1920 缩到视窗大小，小字本来就软；清晰度以导出档为准
- **权利**：社群贴文素材一律 `risk: high` + 画面内来源条（`assets/lib/SourceStrip.tsx`，左下角）+ CREDITS；不去水印、不改内容

成片接法：
- 复制：本卡依赖 `ink-circle-note` 的 `inkLoop`（手绘圈）。复制进成片 `src/cards/` 时两个档一起带，并把 import 改成平铺路径：`'../../_fixtures/…'` → `'../_fixtures/…'`、`'../ink-circle-note/InkCircleNote'` → `'./InkCircleNote'`
- 时间：每个记号的 `at = f(tWord(i, 重点词)) − from`，写在 `timeline.ts`
- 素材：`source-social.mjs --capture` 产出的 `assets/social/<platform>-<id>/post.png` 复制到 `public/social/…`；`pageW = 宽 ÷ 2`
- 同镜加来源条：`<SourceStrip label="X @帐号" prefix="來源" …/>`
- 蒙皮：`marker` → `theme.accent`；暗底 → `theme.bg`；几何、时序、夹边界线不动
