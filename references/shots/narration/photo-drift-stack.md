能量: 低偏中（每张推入一下，其余时间照片只有极缓推近）

## 意图
静态照片满版放 3 秒就是幻灯片；三张照片 Ken-Burns 连放又像婚礼回顾；把照片做成相纸错落堆叠（本卡旧版）则读起来老套。这张卡借用手机上最熟悉的「叠页」语汇：口播点到名字，那张照片以圆角大卡从下方推上来，盖住前一张；前一张缩小、后退、上移、变暗，上缘露出一截留在后面——观众同时读到「现在讲这张」和「刚才讲过那几张」，而照片本身始终是画面上最大的东西。每张卡左下角是「01 / 03」编号 + 大字说明，像限时动态的一页。
（2026-09 改版：使用者从「编辑拼贴 / 叠卡推入 / 横向轮播 / 全版＋进度条」四案里选了叠卡推入。）

## 动效核心
- **几何**（设计坐标）：卡 960×1150、左上 (60, 250)、圆角 34；被压的卡以卡顶为缩放原点，每压一层缩 7%、上移 56px，最上缘约 y 140——露出一截但不进平台顶栏
- **推入**：`at` 之前不渲染；到点后从画面下方（y +1710）推到定位，`enterFrames` 20f `outQuart`，无回弹
- **后退**：后来的卡推入期间，前面每张按「被压层数」连续地缩小、上移、变暗（第一层亮度 0.65，再压一层不再更暗）；不移除、不模糊
- **照片**：`object-fit: cover` 进卡，`focus` 调裁切中心；照片内部 1.04 → 1.08 极缓推近（整镜）
- **说明**：推入后 12 帧起 12 帧淡入 + 上移 12px；卡下半 50% 起一道到 0.72 的暗渐层托字；编号（强调色、26px、字距 4）→ 大字说明（72px 粗）→ 小字补充（32px、72% 白）
- **统一色调**：`tint` 预设 `N.accent` 6%（soft-light，上限 8%），把不同来源的照片拉近

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `photos[].at` | `f(tWord(i, '景点名')) - from`，可再提早 2–3f | 推入 20f；相邻两张间隔 < 40f 会读成「翻牌」，宁可少放一张 |
| `photos` 张数 | 2–3 | 超过 3 张只取最早的 3 张；要讲 4 个以上对象就拆成两镜 |
| `photos[].caption` | 地名 / 人名 / 物件，≤ 8 字 | 72px 单行，超出会截断；说明写「这是什么」，不要塞署名 |
| `photos[].sub` | ≤ 16 字 | 日期、身分、地点补充；可省 |
| `photos[].focus` | `[50, 50]`；主体偏下 → `[50, 62]` | objectPosition 百分比；卡是 960×1150 直窗，横式照片只剩中间一段 |
| `showIndex` | true | 只有 1 张时自动隐藏；整片只用一次叠卡时也可关 |
| `enterFrames` | 20（16–24） | < 16 像弹出；> 24 推入尾段压到下一个词 |
| `tint` | `{ color: theme.accent, amount: 0.06 }`；`null` 关闭 | 同一位摄影师的成组照片可关 |

## 声音
每张推入配一记轻的滑动声，放在句间气口、音量 ≤ 0.25：`transition/sweep-short.mp3`。三张都配会变成节拍器——第一张与最后一张配，中间那张留白；口播密到没有气口时全部不配。

## 已知坑
- **照片比例不一**：卡是直窗，横式照片进来只剩中间约 45% 的宽度；逐张看主体位置后用 `focus` 调。全景照片不适合这张卡，改用 `clip-frame-reveal`
- **可辨识人脸**：大卡 + 大字说明等于「指认」。路人正脸、未成年人、与负面口播搭配的人物照一律换掉或用 `focus` 裁掉；后退变暗**不算**遮蔽——0.65 亮度下脸仍然认得出来
- **混摄影师调色**：并排叠放时色差比单张满版刺眼；6% `tint` 只能拉近，差太多的分到不同镜
- **署名**：文章图片（`rights: article`）要在画面内加来源条（`source-strip`，左下角会压在卡的说明上——来源条改放到卡外、或把说明挪高）；Unsplash 照片进 `CREDITS.md`。三张来源不同时来源条要列全或跟着换
- **说明被字幕盖到**：卡底在 y 1400，说明底约 y 1350；字幕在 y≈1480，不会重叠。若把卡加高，先确认说明不进字幕带
- **第一张独撑太久**：第一、二张的 `at` 间隔超过 3s，画面只有一张卡会显得空——这种脚本改用 `clip-frame-reveal` 单张进框
- `filter: brightness` 与 `box-shadow` 在同一层：投影是黑的，变暗不受影响；换彩色投影的皮时要把投影拆到独立层

## 参考实现
demos/narration/photo-drift-stack/PhotoDriftStack.tsx（`PhotoDriftStackShot` 为镜头本体；demo 210f：三张 FakePhoto，推入于 10 / 78 / 146，含编号与补充说明）

成片接法：
```tsx
const from = f(tLine(5));                        // 本镜起点（timeline.ts 生成）
<PhotoDriftStackShot
  photos={[
    { src: 'media/S05-oirase.jpg',   at: f(tWord(5, '奧入瀨')) - from, caption: '奧入瀨溪流', sub: '青森 · 十和田' },
    { src: 'media/S05-hirosaki.jpg', at: f(tWord(5, '弘前')) - from,   caption: '弘前公園', focus: [62, 50] },
    { src: 'media/S05-sukayu.jpg',   at: f(tWord(6, '酸湯')) - from,   caption: '酸湯溫泉' },
  ]}
  tint={{ color: theme.accent, amount: 0.06 }}
  duration={shot.duration}                       // 要涵盖最后一张推入后至少 2s
/>
```
- `src` 是 `assets/manifest.json`（`source-media.mjs` 产出）里该镜各 `material.file` 对应的 `public/` 路径；`rights` / `attribution_required` 决定要不要叠来源条、进不进 `CREDITS.md`。
- 复制进成片 `src/cards/` 后把 import 改成平铺路径 `'../../_fixtures/…'` → `'../_fixtures/…'`。
- 旧版参数 `layout` / `aspect` / `drift` 已移除（旧成片工程各自保有旧版副本，不受影响）。
- 不给 `src` 时画 `FakePhoto` 占位，可先用来排时序，素材到了再补路径。
