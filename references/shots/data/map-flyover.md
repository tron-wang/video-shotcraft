## 意图
「他从新德里回到北京」这种句子，观众脑中没有地图；风格化点阵地球（`globe-route-flight`）有设计感，但看不出是真实地理。这张卡用 NASA 的真实卫星图：起点城市的灯火近景先交代「在这里」，镜头拉远把两地放进同一个画面，金色航线沿大圆画过去、镜头跟着航线头走，最后推近落在终点、金环弹出——观众同时读到「在哪、多远、往哪去」。预设用夜间城市灯光：黑底上的金黄灯火本身就是黑金调性。
（2026-09 收入：参考 remotion.dev「map-flyover」与 remotionui「map-flight」的动效；程式为本卡自写，不依赖 maplibre / turf。）

## 动效核心
- **图砖**：NASA EOSDIS GIBS 的 Web Mercator 图砖（EPSG:3857，最高 Level 8，公开、免金钥）；`night` = VIIRS Black Marble（夜间城市灯光，png），`day` = Blue Marble Next Generation（jpeg）。取 `L = floor(zoom)` 级，砖在画面上的边长 = 256 × 2^(zoom−L)，经度方向环绕
- **大圆航线**：两地转成单位向量球面插值（slerp），采样 80 点、每帧投影到画面；航线画到 `r`，底下一层 14px 柔光、上面 5px 实线，航头是光点
- **镜头**：进度 `c`（`camFrom → camTo`，`easeInOutCubic`）从起点走到终点；zoom = 近景 − (近景 − 全景) × sin(πc)（两端近、中段远）；镜头中心 = 航线头往航线中点拉 60% × sin(πc)，全景时两端都在画面里
- **全景 zoom**：整条航线外框放进画面 60%；近景 = 全景 + `closeUp`（预设 1.6 级 ≈ 放大 3 倍），上限 Level 8
- **标签**：起点地名胶囊一开始就在、航线起跑后 1s 淡出；终点在抵达后 6 帧浮现；抵达时金环带一次回弹弹出
- 夜间图加 `sepia(0.25)` 把灯火往金色推；四周径向压暗；右下角来源标示（GIBS 规定必须保留）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `from` / `to` | `{ lat, lon, label }` | 地名 2–4 字；两地太近（< 300km）全景 zoom 会超过 Level 8 上限，画面糊——改用城市内的图 |
| `style` | `night` | 新闻 / 财经用 night；旅游、地理题材用 day |
| `camFrom` / `camTo` | 18 / 156 | 镜头比航线早起步、晚收尾，航线才会在画面中间被画出来 |
| `routeFrom` / `routeTo` | 36 / 132 | 对在口播「从…到…」那句；到站对在终点地名那个词 |
| `closeUp` | 1.6 | 1 近景不够近；> 2.2 起点灯火糊成一片（Level 8 上限） |
| `accent` | `theme.accent` | 航线、标记、标签描边同色 |

## 声音
航线起跑可配一声低频 whoosh（0.2），抵达弹环配一声轻「叮」；全部 ≤ 0.35，落在句间气口。

## 已知坑
- **渲染要连网**：图砖在渲染时即时下载（Remotion `<Img>` 会等图载入）；离线或 GIBS 暂时不通时会卡住 / 超时。长片可先把用到的图砖下载到 `public/` 再改 `tileUrl`
- **跨越经度 ±180°**（例如东京 → 洛杉矶）：大圆会跨过换日线，镜头中心的经度插值会绕远路——这种航线请把 `lon` 统一成同侧（洛杉矶用 −118+360 = 242）
- **Level 8 上限**：GIBS 这两层最高 Level 8（约 600m/像素），城市级近景会糊；要街道级请改用其他图源（需要金钥与授权）
- **来源标示不能删**：「Imagery: NASA EOSDIS GIBS」必须留在画面上
- **事实**：地名与方向必须与 `sources/facts.md` 一致；行程示意以外不要画出不存在的路线
