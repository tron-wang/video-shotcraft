## 意图
地图镜头最常见的失败是"一张静止世界地图 + 一条线画过去"——观众看到的是图表，
不是旅程。这张卡让镜头跟着航线走：起点特写交代"从这里出发"，中途拉远让两端同时
在画面里（"原来这么远"），到站推回特写落在终点。距离感来自镜头拉远的幅度，而不是
线的长度。

第二个取舍是**航线领跑、镜头追随**：镜头晚于航线头出发，也晚于它到站。两者同步时
读作"地球自己转过去了"；航线先走、镜头后到，读作"有东西飞过去，镜头在追"。

## 动效核心
- **正交投影 + 单位向量相机基**：`center` = 取景中心单位向量，
  `east = normalize(−c.y, c.x, 0)`，`north = center × east`；点 P 投影到
  `(cx + R·(P·east), cy − R·(P·north))`，`z = P·center`
- **遮挡**（含离地高度的点）：`z < 0` **且** `x² + y² < 1` 才被球体挡住。航线高出地表
  的部分转到球背面边缘时仍然可见——这就是"弧线翻过地平线"
- **镜头偏离航线大圆 9°**：镜头中心 = 沿大圆 `slerp(A, B, cam)`，再朝航线平面法线的
  反方向旋开 9°。正对航线所在大圆看，航线投影永远是一条直线；偏开后才看得出弧度和
  离地高度（本卡首版没偏，整条航线是一根直棍）
- **一条曲线管推拉**：`R = lerp(1150, 1020, cam) × (1 − 0.56·sin(π·cam))`——两端特写、
  中段拉远
- 航线头 `bezier(.45, 0, .25, 1)`（起飞加速、巡航、刹车）f18→118；镜头
  `inOut(sin)` 更软，f24→128
- 航线离地高度 `lift·sin(π·s)`，`lift = 0.16 × 航程 / 90°`：长航线弧更高
- **陆地点阵**：1.5° 陆地掩码（240×120 位图，base64 内嵌在组件里）→ 逐纬线按周长
  等距取点 `n = round(360·cos(lat) / 1.5)`，约 5k 个单位向量挂载时算一次；逐帧按 z 分
  6 档透明度，每档合并成一条 Path2D 一次 fill
- 球面边缘自然压暗：点半径 ×(0.55 + 0.45z)、透明度 `0.12 + 0.88·z^0.8`，不用额外画光照；
  球体本身是偏左上的径向渐变 + 1.16R 的蓝色大气辉光
- **到站**：航线头 8f 内收掉；终点两圈涟漪（间隔 9f，30f 扩到 72px）；城市名
  `easeOut(back 1.6)` 12f 弹入。起点城市名出发 20f 后降到 55% 不透明度
- **hold**：到站后地球继续东转 5°（`out(quad)`），画面不定格
- 城市名放在航线**反侧**（起点名在左、终点名在右），航线不压字

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 起点 / 终点特写半径 | 1150 / 1020 px | <900 看不出"特写"，城市周边地形不可读；终点略远于起点给城市名留上下文 |
| 中途拉远 PULL | 0.56（峰值半径 ≈500px） | 峰值时整颗地球完整入画、两端都在圆盘内；<0.4 两端不能同框，距离感丢失 |
| 镜头偏离大圆 | 9° | 0° 航线是直线；>15° 起点/终点特写时城市离画面中心太远 |
| 镜头滞后 | 出发晚 6f、到站晚 10f | 同步 = 地球在转；滞后 >20f 航线头冲出画面 |
| 航线时长 | 100f（航程约 90°） | 航程更长按比例加；<70f 拉远还没到峰值就开始推回 |
| 航线离地 | 0.16 × 航程/90° | 太低贴地看不出是航线；>0.3 像抛物线导弹 |
| 点阵间距 | 1.5° | 1° 远景糊成色块；≥2.5° 英国、新加坡周边这类小块陆地直接消失 |
| 涟漪 | 两圈、间隔 9f、30f、72px | 单圈读作点击；三圈以上变雷达 |
| 到站后 hold | ≥50f，东转 5° | <30f 城市名来不及读；完全静止读作定格 |

## 已知坑
- 1.5° 掩码下小地标会失真：英国只剩十几个点、新加坡落在马来半岛尖端。城市针用真实
  经纬度，不要为了"落在点上"去挪坐标
- 掩码来自 Natural Earth 1:110m 陆地多边形的逐纬线扫描线栅格化；南极内陆几行原始
  多边形没有闭合到极点，栅格化时要强制填满（组件内嵌的掩码已处理）
- 航程接近 180°（对跖点）时大圆不唯一，slerp 会让镜头乱转。超过 150° 的航线拆成
  两段或加中转点
- 相机基用 Z 轴叉乘求 east，镜头中心经过南北极附近时退化。极地航线要换参考轴
- 城市名是 DOM（字形清晰，≥40px），但可见性要跟投影一起算：转到球背面或贴近边缘
  （z < 0.15）时隐藏，否则名字会浮在地球外面
- 点阵按透明度分档合并成少数几条 Path2D 再 fill，不要每个点单独 beginPath/fill
- 城市和航线是地理事实，可以直接用；不要叠加真实航空公司名、航班号或机场品牌
