---
name: quote-plate
一句话: 引述卡——大号开引号先到，句子按旁白的断句一个分句一个分句地出现，读完才给署名（姓名 · 身分）
适用: 口播片里"某人说了一句话"的那一镜（当事人回应、官方说法、受访者原话）；一镜一句、一个说话者
时长: 约 4–8s（demo 180f）；最后一个分句念完后至少留 0.8s 给署名
能量: 低（安静的阅读镜，节奏完全交给人声）
input: [text, photo, video]
narration: quote
---

## 意图
引述整句一次摆出来，观众两秒就读完，剩下的四秒在等旁白——画面和声音脱节。这张卡让句子**跟着旁白的断句出现**：旁白念到哪个分句，那个分句才浮出来，观众是"跟读"而不是"抢读"。但它不是卡拉 OK：已经出现的分句保持全亮，不压暗、不逐字打字——这是一句要被完整读懂的话，不是歌词。署名放在最后，先听内容、再知道是谁说的，和旁白"……负责人这样说"的语序一致。

## 动效核心
- 版面从第 0 帧就按**整句**排好：每个分句是一个块，未到点的 `visibility: hidden` 照样占位——分句出现时已有文字一个像素都不重排
- 每个分句在自己的 `at` 帧短升 10px + 淡入，7 帧、`outCubic`；不逐字、不模糊、不缩放
- 开引号是两根直条拼的「（强调色，104×120、笔画 16），比第一个分句早 6 帧到——先告诉观众"接下来是引述"
- 署名：强调色细线 64×4 从左伸出（10f），姓名（粗）· 身分（细、`N.bar`）晚 3 帧短升淡入
- 整句至多一处 `emphasis` 染强调色；只换颜色不换字重，字宽不变、版面不变
- 镜内的"活"：底图 1.00→1.04 极缓推近；文字组反向 1/1.03→1.00（文字右缘贴着 x=900，不能往外放大）
- 只做靠左：多行中文置中时每行行首位置都在变，眼睛每换一行要重新找起点；分句长短不一时轮廓像棵树，读成"几个短语"而不是"一句话"。靠左的行首是一条直线，和左侧的引号、署名细线对成一列

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `phrases[].text` | 每个分句 6–13 个全形字 | 在旁白稿的标点处切（每个逗号都切）；≤ 13 字的分句在最小档能独占一行，版面最干净 |
| `phrases[].at` | `f(tWord(i, 分句首词))` | 分句起点是最准的时间戳；不要用句中的词去推 |
| `markAt` | 首分句 `at − 6`（钳到 ≥ 0） | 引号比字早 5–8f；早太多就成了空画面上孤零零一个符号 |
| `attributionAt` | 末分句 `at + 18` | 预设值适合 ≤ 6 字的短尾句；尾句长时改用 `f(tLineEnd(i))` 或旁白念到说话者名字的那个词 |
| `emphasis` | 2–6 字 | 整句最多一处，且必须完整落在某一个分句内（跨分句不会染色）；染的是"这句话的新闻点"，不是形容词 |
| 字号三档 | ≤ 24 字 84px / ≤ 36 字 72px / ≤ 48 字 62px | 按整句字数（全形 1、半形 0.55）选档；若最长分句在该档放不进一行而最小档放得进，自动降到最小档换"一分句一行"。> 48 字请拆成两张卡 |
| 行高 / 字体 | 1.5 / `N.serif` 700 | 衬线体是"这是别人的原话"的信号；旁白字幕用黑体，两者才分得开 |
| 文字块 | `left 84`、宽 816（右缘 x=900） | 不要加宽：x>900 在 y 900 以下是平台按钮带 |
| 垂直位置 | 整组中心 y≈770，顶 ≥ 190、底 ≤ 1380 | 按估算行数自动置中；48 字 6 行时整组约 y 350–1190 |
| `overMedia` / `dim` | false / 0.62 | 压在照片 / 实拍上时开；亮天空、雪景调到 0.7。比 `stat-punch` 的 0.55 重一档，因为这里是要读的小字 |
| `accent` | `N.accent` | 引号、强调词、细线同色 |
| 入场 | 7f、上升 10px | 上升 > 12px 会读成"字幕弹出"；< 5f 像闪现 |

## 声音
这张卡整镜都在人声底下，基本不配音。要配只配一记：开引号入场用 `ui/switch-tap.mp3` 或 `paper/paper-slide.mp3`，音量 0.2–0.25，且 `markAt` 必须落在上一句结束后的气口里；落不进气口就不配。分句出现**不要**逐个配音（三连点击声会盖住人声的节奏）。署名不配音。全部 ≤ 0.35。

## 已知坑
- **引号里的字必须与 `sources/facts.md` 逐字一致**：不改写、不缩句、不调语序。嫌长就换一句短的，或改用旁白转述 + 别的卡；`\n` 手动断行只影响排版，不算改字
- **`word-break: keep-all` 不能用在句子上**：中文没有空格，keep-all 会让整个分句变成不可折行的一个词，超过行宽就直接冲出右缘。句子用 `line-break: strict` + `word-break: normal`（禁止行首出现「，。」」等收尾标点；demo 与 48 字测试句的静帧里没有出现，但换字体 / 换句子后仍要看一眼静帧），keep-all 只用在单行的署名上
- **浏览器不懂中文分词**：放不进一行的分句会被 `text-wrap: balance` 平均折成两行，折点可能落在词中间（实测「今年報名人數比去年同/期成長…」、「第一/次參加」）。对策依序：① 在标点处切得更细；② 在分句 `text` 里手写 `\n` 指定折点；③ 改稿
- **垂直置中靠估算行数**：不量 DOM，行数用"字数 ÷ 每行字数"估。`balance` 或行末标点挤压让实际行数差一行时，整组会偏 40–60px——仍在 SAFE 内，但出静帧时看一眼
- **预设 `attributionAt` 对长尾句太早**：+18f 时旁白往往还在念最后一个分句，署名会抢读。尾句 > 6 字就显式传值
- **一处强调**：`emphasis` 只染第一个含它的分句里的第一处；想染两处说明这句话有两个重点，应该拆成两镜
- **人像照片的暗示**：引述后面垫一张人脸，观众会认定"照片里的人说了这句话"。只能用说话者本人的照片（且 manifest 有授权），否则用中性场景（建筑、现场、物件）或纯 `N.bg`
- **说话者未具名**：来源只写"負責人""知情人士"时，`speaker` 照来源的称呼写，不要自己补姓名或头衔；`role` 写单位 / 媒体
- **半形字**：英文、数字按 0.55em 估宽，整句英文引述会被估短、选到过大的字号档——英文引述请手动确认静帧或改用别的卡

## 参考实现
demos/narration/quote-plate/QuotePlate.tsx（导出 `QuotePlateShot` / `QuotePlateProps` / `QuotePhrase` / `quotePlateLayout` / `QUOTE_PLATE_MAX_CHARS` / `QUOTE_PLATE_DURATION`；demo 180f：三个分句 @24 / @70 / @112，署名 @130，底是压暗 62% 的 `FakePhoto`）。

成片接法：
- 时间：把旁白那一句（第 `i` 句）在标点处切成分句，每个分句的 `at = f(tWord(i, 该分句的第一个词)) − from`；`from` 取该镜起点（通常是上一句的 `end`，让引号落在气口里）。`attributionAt` 用 `f(tLineEnd(i)) − from`，或旁白在引述后才说"……負責人表示"时用 `f(tWord(i + 1, '負責人')) − from`。全部写在 `timeline.ts`，不手敲帧号；稿子改了词不在，`tWord` 会直接抛错
- 文字：`phrases[].text` / `speaker` / `role` 从 `sources/facts.md` 的引述条目逐字取；旁白稿里念的引述也必须是同一串字
- 素材：`input: [text, photo, video]`。纯文字时不传 `overMedia`；有素材时 `<QuotePlateShot overMedia …><Img src={staticFile(manifest 里该镜的 file)} style={{ width: '100%', height: '100%', objectFit: 'cover' }} /></QuotePlateShot>`，实拍换 `<OffthreadVideo muted>`。不吃 `boxes.json`。用到文章图片时同镜加来源条（`assets/lib/SourceStrip.tsx`）
- 蒙皮：`N.serif` → `theme` 的引述 / 标题衬线体，`accent` → `theme.accent`；浅底风格档把 `N.onDark` / `N.bar` 换成深色字并把暗幕换成亮幕。字号档、行高、入场时序与几何不动
