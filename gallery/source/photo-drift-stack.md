---
name: photo-drift-stack
一句话: 2–3 张照片洗成相纸错落叠放，讲到谁谁才滑进来落在最上面，先到的变暗略缩留守，整叠带视差极缓漂移
适用: 口播片里「只有照片、没有实拍」的 b-roll 段落（旅游景点、人物旧照、产品图、活动现场）；一句话里连点 2–3 个对象
时长: 5–9s（每张至少留 2s；demo 210f = 三张，进场于 10 / 78 / 146）
能量: 低（每张进场一下，其余时间只有几 px/秒的漂移）
input: [photo]
narration: broll
---

## 意图
静态照片满版放 3 秒就是幻灯片；在照片里做 Ken-Burns 推拉，三张连放又像婚礼回顾。这张卡把照片当成桌上的实体相纸：口播点到名字，那张相纸才放上来压在最上面，前面的退成背景但还在——观众同时读到「现在讲这张」和「刚才讲过那几张」。画面的「活」来自相纸之间的相对位移（各层漂移速率不同），照片内部一动不动，所以不会和口播抢注意力，也不会把照片的构图推坏。相纸边与 `clip-frame-reveal` 的 `paper` 框式同比例、同投影：同一部片里影片进框、照片成叠，读起来是同一本相册。

## 动效核心
- 几何先算落定构图（`photoStackLayout`）：n 张的错位范围 + 说明行 + 漂移行程 + fan 的旋转外接框，全部扣掉之后再定相纸尺寸，整组在 SAFE 内置中。任何一帧都不出 SAFE
- 相纸边 = 相纸宽 × 34/930（上左右）与 × 82/930（下），就是 `paper` 框式 34/34/82/34 的等比缩放；落定投影 `0 26px 70px rgba(0,0,0,.55)` 同值；素材窗内缘同一条 1px `N.line` 0.5
- `cascade`：每张往右下错 (64, 96)，不旋转；`fan`：最上面那张居中、下面两张左右各偏 46、逐张下移 44，每张一个**固定**角度（下层 1.5–2.5°、最上层 0.7–1.2°，正负交替，上限 ±2.5°），角度由 `seed` 决定、永不随帧变化
- 进场：`at` 之前不渲染。到点后由「它错开的方向」滑入 84px（outQuart，无回弹，`enterFrames` 16f）；淡入只占前 35%（约 6f）；投影同步由 `0 6px 16px / .12` 加深到落定值——读作「纸放到桌上」
- 退后：新相纸的 `at` 一到，之前每张各退一级，12f inOutQuad：第一级亮度 0.62 / 缩放 0.97，第二级 0.52 / 0.945。只变暗变小，不移除、不模糊
- 漂移：以落定构图为中点，全镜 −½ → +½ 线性走完 `drift`（最上层），下两层 0.6× / 0.35×。速率按**落定后的层序**固定给每张，不随「现在谁在最上面」切换——否则换层那一帧会有速度折点
- 说明：只挂在当前最上面那张的下方，跟着那张相纸一起漂；落定前 4f 起 10f 淡入 + 上移 8px；下一张到场时 8f 淡出，同时被新相纸盖住（说明的层级在下一张相纸之下）
- 统一色调：每张照片上盖一层 `tint`（预设 `N.accent` 6%，上限 8%），在相纸白边之内——白边保持纯净才像相纸

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `photos[].at` | `f(tWord(i, '景点名')) - from`，可再提早 2–3f | 进场 16f，词音节落下时相纸大致落定最顺；相邻两张间隔 < 40f 会读成「洗牌」，宁可少放一张 |
| `photos` 张数 | 2–3 | 超过 3 张只取最早的 3 张；要讲 4 个以上对象就拆成两镜 |
| `layout` | 旅游 / 生活 → `cascade`；人物旧照、回忆感 → `fan` | cascade 每张露出左缘与上缘一条，层次最清楚；fan 下层只露边角，比较像「一叠」而不是「三张」 |
| `aspect` | 直式 4/5；横式照片为主 → 3/2 | 窗的比例，全叠共用。横式窗下整组变矮，上下留空由底色承接 |
| `photos[].focus` | `[50, 50]`；主体偏右 → `[70, 50]` | objectPosition 百分比；每张各调，见已知坑 |
| `drift` | `{ dx: -18, dy: -26 }`（7s）| ≈ 4.5 px/s。镜长加倍时位移也近似加倍才保持同样速率；超过 8 px/s 会读成「在滑走」 |
| 视差倍率 | 1 / 0.6 / 0.35 | 层间相对位移整镜约 10–17px——刚好看得出有深度。拉大会像相纸在桌上自己爬 |
| `enterFrames` | 16（12–20）| < 12 像弹出；> 22 滑入尾段太黏，压到下一个词 |
| 滑入距离 | 84px（上限 90）| 再远就成了「飞入」，视线会离开口播字幕 |
| 退后 | 0.62 / 0.97，12f | 亮度 > 0.75 时前后两张争主角；< 0.5 下层读不出是照片，「留守」就失去意义 |
| `tint` | `{ color: N.accent, amount: 0.06 }`；`null` 关闭 | 同一位摄影师的成组照片可关；混来源时 0.05–0.08。进片时颜色换成风格档的主色 |
| `seed` | 0 | 只动 fan 的角度与几 px 的错位抖动（以及 FakePhoto 占位）；同一部片多次用这张卡时换 seed，避免每叠一模一样 |

## 声音
每张落定配一记纸声，放在句间气口、音量 ≤ 0.3：`paper/paper-slide.mp3`（首选，与 clip-frame-reveal 的 paper 框式同一个声音）或 `paper/paper-move-quick.mp3`。三张都配会变成节拍器——第一张与最后一张配，中间那张留白；口播密到没有气口时全部不配。漂移与退后不配音。

## 已知坑
- **照片比例不一**：同一叠共用一个 `aspect`，横式照片进 4/5 直窗只剩中间约 53% 的宽度。逐张看主体位置后用 `focus` 调裁切中心；三张里两张以上是横式，就整叠改 `aspect={3/2}`，不要为了单张迁就。比例差异极端（全景 + 直式人像）的不要放同一叠
- **可辨识人脸**：相纸 + 白边 + 说明文字等于「指认」。路人正脸、未成年人、与负面口播搭配的人物照一律换掉或用 `focus` 裁出窗外；manifest 里确认该照片授权含肖像。退后变暗**不算**遮蔽——0.62 亮度下脸仍然认得出来
- **混摄影师调色**：图库 A 偏青、文章配图偏暖，叠在一起色差比单张满版时刺眼得多（并排直接比较）。预设的 6% `tint` 只能拉近、不能救回差距很大的组合；选材时就挑色温接近的，差太多的分到不同镜
- **署名**：文章图片（`rights: article`）用到的这一镜画面内要有来源条（`source-strip`），Unsplash 照片进 `CREDITS.md`。一叠三张来源不同时，来源条要列全或在换张时跟着换，不能只标最上面那张的来源就让另外两张搭便车。说明行写的是「这是什么」，不要拿来塞署名
- **漂移不要取整**：位移每帧约 0.1px，`Math.round` 之后变成每 8 帧跳 1px，肉眼看是抖。保持小数、用 2D `translate`（不要 `translate3d`）
- **淡入期间会透出下层**：相纸半透明的那几帧看得到底下那张的图，像叠印。所以淡入压在前 35%（≈6f），那时滑入也走完了约 85%；不要为了「柔一点」把淡入拉到和 `enterFrames` 一样长
- **单张留守期构图偏左上**：几何按落定构图算，第一张进场后、第二张到之前，画面上只有一张偏左上的相纸。第一、二张的 `at` 间隔超过 3s 会显得空——这种脚本改用 `clip-frame-reveal`（`kind="photo"`）单张进框
- `filter: brightness` 与 `box-shadow` 在同一层：投影是黑的，变暗不受影响，但进片换成彩色投影的皮时要把投影拆到独立层
- 说明只有一行、`nowrap` 截断：相纸宽约 760px、34px 字，扣掉前导短线约放得下 20 个全形字，建议 ≤ 14 字

## 参考实现
demos/narration/photo-drift-stack/PhotoDriftStack.tsx（`PhotoDriftStackShot` 为镜头本体；`photoStackLayout` 可单独取几何，给来源条 / 其他叠层对位）

成片接法：
```tsx
const from = f(tLine(5));                        // 本镜起点（timeline.ts 生成）
<PhotoDriftStackShot
  layout="cascade"
  photos={[
    { src: 'media/S05-oirase.jpg',   at: f(tWord(5, '奧入瀨')) - from, caption: '奧入瀨溪流' },
    { src: 'media/S05-hirosaki.jpg', at: f(tWord(5, '弘前')) - from,   caption: '弘前公園', focus: [62, 50] },
    { src: 'media/S05-sukayu.jpg',   at: f(tWord(6, '酸湯')) - from,   caption: '酸湯溫泉' },
  ]}
  tint={{ color: theme.accent, amount: 0.06 }}
  duration={shot.duration}                       // 漂移的分母；要涵盖最后一张落定后至少 2s
/>
```
- `src` 是 `assets/manifest.json`（`source-media.mjs` 产出）里该镜各 `material.file` 对应的 `public/` 路径；`rights` / `attribution_required` 决定要不要叠来源条、进不进 `CREDITS.md`。
- `at` 是镜内帧号：词锚 `f(tWord(i, '词'))` 减掉本镜起点。词锚跨句（上例第三张在下一句）没问题，只要都落在本镜内。
- 不给 `src` 时画 `FakePhoto` 占位，可先用来排时序，素材到了再补路径。
