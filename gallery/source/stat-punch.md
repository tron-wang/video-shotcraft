---
name: stat-punch
一句话: 全片那一个数字，正好砸在旁白说出它的那个词上——大数字落下、弹一次、落定，单位与说明随后跟上
适用: 口播片的数据段 / 数字钩子（成长率、浏览数、金额、名次）；一镜只讲一个数字
时长: 约 3–5s（demo 120f）；词锚后至少留 1.2s 让人读完说明行
能量: 中高（全片最重的一记，全片最多用两次）
input: [text, video, photo]
narration: data
---

## 意图
观众听到「百分之四十一点九」的同一瞬间，眼睛要看到 41.9——早一拍是剧透，晚一拍是字幕。所以这张卡在词锚前什么都不画（只有素材在走），词锚帧数字直接以 1/3 不透明度、1.28 倍砸入，3 帧内到满，弹一次就停。数位滚动只占入场的前 60%，是「砸」的余震而不是计数器表演；说明行晚于落定才出现，读作对数字的注解。

## 动效核心
- 词锚 `at` 之前：数字、单位、细线、说明行都不进 DOM（不是 opacity 0 的占位，更不是灰显）
- 数字落定是 τ = frame − at 的纯函数：`s(τ) = 1 + 0.28·(1 − τ/5)·e^(−τ/4)`。临界阻尼型——只有一个过零点（τ=5）和一个谷底（τ=9，0.976），之后单调回到 1，数学上保证「最多弹一次、之后不晃」
- 位移共用同一条曲线：`y = −160·(s − 1)`，从上方 45px 落下、过冲 4px 后归位；缩放与位移永远同相
- 数位滚动 `rollFrames`（预设 12f = 入场 20f 的 60%）：outCubic 从「终值的一半、但不低于同位数最小数」滚到终值（41.9 从 20.9 起、124,000 从 100,000 起），τ ≥ rollFrames 时直接取终值，必定停在 `value` 上
- 每个数字一格 0.6em、「,」「.」一格 0.28em，格宽由终值字串决定——滚动时数字不会横向抖
- 单位（右侧小字）与细线、说明行在 `at + labelDelay` 起 9f 淡入上移；第二说明行再晚 5f
- 背景：实拍 / 照片层（children）做 1.00→1.04 极缓推近，上盖 `N.bg` 55% 暗幕；无素材时是纯底 + 一团极淡的光

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `at` | `f(tWord(i,'四十一')) − 镜头 from` | 对准数字词的**起点**而不是句首；宁早 1–2 帧不要晚，晚了读作字幕 |
| 落定曲线 A / T0 / TAU | 0.28 / 5 / 4（τ=0→1.28、τ=5→1.00、τ=9→0.976、τ=18→0.992、τ=30→0.999） | A 是起始放大量，>0.35 在直式里会冲出 SAFE；T0 是第一次穿过 1 的帧数，越小越硬；TAU 管余波长度，>6 会拖泥带水。三个数只调 A，另外两个动了要重看 τ=9 的谷底别低于 0.96 |
| 入场不透明度 | τ=0 即 1/3，τ=2 到满 | 砸入不做慢淡入；淡入超过 4f 冲击感就没了 |
| `rollFrames` | 12（入场 20f 的 60%） | 数字位数多（≥6 位）可到 16；超过 20 就变成计数器卡，和旁白脱节 |
| 滚动起点 | max(终值÷2, 同位数最小数) | 保持位数不变才不会出现左侧空格。第一版「从 0 滚」在 124,000 上 τ=0 只剩右侧一个孤零零的 0，整个砸入瞬间是空的——起点一定要和终值同位数。只有终值恰为 10^n（100、1,000）时首格会空 1–2 帧 |
| `labelDelay` | 18（数字视觉落定约 τ=14，再等 4 帧） | 旁白紧接着念单位（「…点九趴」）时可缩到 12；<10 会和过冲抢视线 |
| `fontSize` | 预设 200（含分隔符 6 字符的数字，连 τ=0 的 1.28 倍都在 SAFE 内）；≤4 字符可放大到 300（demo，实得约 298） | 只是上限：`(前缀 + 数字格 + 单位) × 1.28` 的估宽超过 SAFE.w×0.97 时自动等比缩小，所以再长的字串也不会在砸入瞬间出界 |
| 单位字号 | 数字的 0.36 倍，基线对齐，`N.onDark` | 单位用白、数字用强调色，主次才分得开 |
| 说明行 | 56px / 700；第二行 36px / 500 / 66% | 说明行 ≤ 12 字，一行；再长就拆到第二行 |
| `dim` | 0.55 | 素材偏亮（天空、白墙）拉到 0.65；低于 0.45 数字压不住画面 |
| 数字垂直中心 | y=700 | 说明两行时整组重心约 y=800，仍在 SAFE 中段；不要下移，y≈1480 是字幕 |

## 声音
- 砸入（对 `at`）：`impact/hit-weak.mp3`，音量 0.30；想再实一点换 `impact/bass-hit-short.mp3` 0.25。不要用 `impact-cine-big` / `impact-epic-trailer` 这类长尾大冲击，尾巴会盖住下一个词
- 说明行出现（对 `at + labelDelay`）：`ui/ui-tone-quick.mp3` 或 `ui/switch-tap.mp3`，音量 0.15；旁白此刻还在念就省掉
- 口播片音量一律 ≤ 0.35。数字词本身正在被念出来，砸入声等于叠在人声上——这是全片唯一允许压词的一记，所以更要短、要低；同一片第二次用这张卡时把砸入声再降到 0.22

## 已知坑
- **单位占位导致数字先偏左**：整组（数字 + 单位）一起置中，单位到点前只占位不画，所以 `at` 到 `at+labelDelay` 这 0.6s 数字视觉上偏左半个单位宽。「%」「萬」这种 1–2 字单位看不出来；「萬次瀏覽」这种长单位偏移会到 150px 以上——长单位请写进 `label`，`unit` 只留 1–2 字
- **不要用 `toLocaleString`**：渲染机的 ICU / locale 不同会吐出不同分隔符，卡内用整数运算自己排千分位
- `value × 10^decimals` 要在 2^53 以内；「12.4 萬」请传 `value=12.4, decimals=1, unit='萬'`，不要传 124000 再指望它自己转单位
- 换字体后必须重看格宽：`DIGIT_EM=0.6` 是按 PingFang / Noto Sans 的粗体数字标的，换成窄体（DIN、Bebas 类）数字间会发疏，要同步调小（约 0.52），否则自动缩字的估宽也跟着错
- 前缀与单位的宽度是估算（全形 1em、半形 0.62em），不是实测；用了特别宽的字（「＄」全形、emoji）时出一张落定静帧确认没出 SAFE
- 自动缩字是按起始最大倍率（1.28）算的，不是按落定宽度：第一版按落定宽度算，6 字符 + 「%」在 τ=0 会宽到 1155px 直接出画面。代价是落定后长数字两侧会留约 12% 空——这是对的，别为了「撑满」把 A 调回去却忘了这条
- 词锚距镜头开头 > 1.5s 时必须有素材承载（`overFootage` + children），纯底空等会违反分镜检核表第 4 条；词锚距镜尾 < 0.6s 则说明行来不及读，把锚提前或换镜
- 画面上的数字必须与 `sources/facts.md` 一致（终检项）；四舍五入由你传入的 `value` / `decimals` 决定，卡不会替你改数

## 参考实现
demos/narration/stat-punch/StatPunch.tsx（`StatPunchShot` 是镜头本体，不含 NarrationStage；`statPunchSettle(τ)` 落定曲线单独导出，可给同镜其他元素借相位）

成片接法：
```tsx
// timeline.ts 给出本镜 from / duration；tWord 来自 timing.ts
const at = f(tWord(2, '四十一')) - shot.from;
<Sequence from={shot.from} durationInFrames={shot.duration}>
  <StatPunchShot value={41.9} decimals={1} unit="%" label="比去年同期成長"
    at={at} duration={shot.duration} accent={theme.accent} overFootage>
    <OffthreadVideo src={staticFile(manifest.byId['queue-broll'].file)} muted
      style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
  </StatPunchShot>
</Sequence>
```
- 时间点：只有 `at` 一个词锚，取数字词起点；`labelDelay` / `rollFrames` 是相对量，不用换算
- 素材：`material.mode` 为 video / photo 时从 `assets/manifest.json` 取档当 children（照片用 `<Img>`）；mode 为 text 时不传 children、`overFootage={false}`。这张卡不吃 `boxes.json`——要在网页截图上点出数字请用 `marker-sweep` / `loupe-peek`
- 蒙皮：`accent` → `theme.accent`，`N.onDark` / `N.bg` / `N.font` 整组换 token；不改曲线常数与格宽比例（换字体例外，见已知坑）
