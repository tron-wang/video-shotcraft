## 意图
陈列一组视觉作品时，平铺网格读作"目录"，逐张全屏读作"幻灯片"。把它们叠成一摞斜放，
观众同时看到"当前这张"和"后面还有很多"，数量感与单张的完整度兼得。

动作的关键是**谁先动**：最前一张先原地淡出让位，后面的才往前补——淡出和前移几乎同时，
但淡出早 3f。如果前一张飞走、后一张再补位，读作"翻牌"；原地溶解再推进，读作"一叠纸被
轻轻往前送"，节奏更安静，适合作品本身就是主角的场景。

## 动效核心
- **正交等轴，不用 perspective**：每张海报 `transform: matrix(0.9, 0.2, 0, 1, 0, 0)`
  ——`scaleX .9` 做侧转压缩、`skewY` 的 tan 取 .2 让右边比左边低。前后海报同尺寸，
  纵深只靠两件事读出来：斜线排布（每槽 `+104px, −84px`）和逐槽压暗（`brightness` 每槽 −.13）
- **槽位由帧直接推出**：`beat = floor(f / 48)`，第 i 张的槽位 `slot = (i − beat) mod 6`；
  拍内进度 `p = ease((local − 20 − (slot−1)·1) / 18)`，位置 `pos = slot − p`。
  无跨帧状态，任意帧可独立渲染
- **最前一张**（slot 0）：比前移早 3f、从第 17f 起 26f 内溶解，比前移长——补位落定后它
  还在缓缓散去。两条曲线分开：`opacity 1→0` 用 sine 慢进慢出 `bezier(.37, 0, .63, 1)`，
  没有"突然开始变透明"的一下；`pos 0→−0.4` 用 out 曲线 `bezier(.22, .61, .36, 1)`
  先走后停，一开始就在让位，快消失时几乎静止，不会带着残影飘走
- **可见窗口**：槽 0–3 全亮；槽 4→3 的那一格线性淡入；槽 5 始终不可见。
  前移结束时（第 42f）槽 5 的海报刚好到槽 4，下一拍接上，循环无缝
- **层级**：`zIndex = 1000 − pos·100`，正在淡出的那张 pos 为负，永远在最上面
- 前移缓动 `bezier(.65, 0, .35, 1)`（对称慢进慢出，读作被推送而不是弹射）
- 海报自带的小动作（示例里白底海报的圆点漂移）按"整片整圈数"取速度，
  第 288 帧与第 0 帧逐像素一致

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 拍长 | 48f | <30f 来不及看清单张；>60f 读作停住了 |
| 静置 | 20f（拍首） | 放在拍首，首帧就是落定状态，缩略图不会截到半透明 |
| 前移 | 18f | <10f 读作跳格；>24f 整摞拖泥带水 |
| 后排晚起步 | 1f/槽 | 0 读作一块硬板在平移；>3f 后排像被拉长的弹簧 |
| 淡出时长 | 26f（sine 慢进慢出） | <16f 读作"啪"地消失；线性曲线起点和终点都有一下顿挫 |
| 淡出提前 | 3f | 与前移同帧时两张在槽 0 短暂叠成双影 |
| 淡出滑移 | .4 槽（out 曲线先走后停） | 0 时溶解与补位完全重叠；>.6 读作被扔出去；和透明度共用同一条曲线时，尾段残影还在飘 |
| 可见张数 | 4 | 3 张数量感弱；≥5 张时最后几张太暗、斜线太长出画 |
| 槽距 | +104, −84px | 比值决定斜线角度；太小时后排只露一条边，读不出是海报 |
| 横向压缩 / 斜切 | .9 / .2 | 压缩 <.8 时海报显得瘦长；斜切 >.35 时正面文字读不清 |
| 逐槽压暗 | .13 | 0 时白底海报叠在一起分不出前后；>.2 后排发黑 |
| 海报尺寸 | 480×520（接近方形） | 压缩后视觉宽高比约 .83；3:4 再乘上压缩会显得太瘦长。整摞高度控制在画面 80% 左右，留出淡出滑移的余量 |

## 已知坑
- **不要加 perspective**：透视会让后排海报变小、斜线变成放射状，失去"整齐一叠"的
  图形感；同时每张海报的梯形变形会随位置变化，前移时看起来在扭动
- 首帧要落在静置段：静置放在拍尾时，第 0 帧正处于淡出中，gallery 缩略图是半透明的
- 可见窗口外至少要多一张不可见的海报（6 张轮播只露 4 张），否则补位的那张会从
  正在淡出的那张身上"穿出来"
- 连续两张白底海报相邻时，没有压暗就分不出前后——亮度差比阴影更可靠（深色背景上
  阴影看不见）
- 海报内部动画若用 `frame × 速度` 直接取模，循环点会跳一下；速度要按整片整圈数取
- 示例海报全部是中性占位设计，替换成真实作品时注意文字密度：斜切后小于 20px 的字
  基本读不出，海报只需要"看起来是一张完整的设计"，不需要读懂
