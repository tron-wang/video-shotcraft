---
name: bar-grow-compare
一句话: 2–4 个量按旁白的顺序比大小——念到哪一项，那根柱子才从基线长出来、数值跟着数到位；前面的柱子降权留守，最后重点那一根换成强调色
适用: 口播片的数据段里「比较」型的句子（近三年人数、各管道占比、我方 vs 对手）；2–4 项、同一种单位；只有一个数字请用 stat-punch
时长: 约 5–8s（demo 180f）；每项之间至少 1s，最后一个词锚后留 ≥ 1.5s 给落定换色与读图
能量: 中（稳步累积，不砸；全片的「讲道理」镜头）
input: [chart]
narration: data
---

## 意图
比较句是一项一项念出来的，图也要一项一项长出来：观众的眼睛永远只被要求看「现在正在讲的那一根」，前面讲过的退到 45% 留在原地当参照物。柱高与柱顶数字共用同一条曲线，所以任何一帧暂停，数字都等于那一刻柱子代表的量——这张图从头到尾不说谎：轴从 0 起、生长不过冲、数字不先到。全部讲完后才揭晓重点：那一根换成强调色，其余退到 55%，画面从「逐项陈述」变成「结论」。

## 动效核心
- 词锚 `at` 之前：该项的柱、数值、类别名都不进 DOM。坐标骨架（基线、格线、轴数字、来源行）不是数据，随标题在 `titleAt` 淡入（9f）
- 生长：`p = outQuart((τ+1) / growFrames)`，τ = frame − at；单调、**无过冲**（过冲的柱子等于谎报了几帧数字）。词锚当帧就已有一截（22f 时约 17%），不会晚一拍
- 数值标签骑在柱顶（柱顶上方 12px），显示 `round(终值 × p)`——与柱高同一个 p，`p = 1` 时直接取终值，必定停在 `value` 上。定宽数字格：每个数字 0.6em、「,」「.」0.28em，格数由终值字串决定、靠右对齐，滚动时不横向抖（与 stat-punch 同一组比例）
- 数值置中于柱，单位（0.5 倍字号、80%）**悬挂**在数字右侧不参与置中——数字永远对准柱心
- 降权留守：比自己晚的下一个 `at` 一到，10f（outCubic）内柱子退到 45% 不透明度、文字退到约 59%，位置与尺寸不动
- 落定：`settleAt = 最后一个 at + growFrames + 10`，12f（inOutCubic）内 `highlight` 那根叠上 `N.accent`（柱与数值都换色），其余回到 `N.onDark` 55%；没有任何 highlight 时全部回到 100%
- 换色做法是「同形叠两层、上层渐显」，不解析颜色字串——换皮时 token 可以是任何 CSS 颜色
- 相机：整个图表容器从 1/1.04 推到 1.00（贴满 SAFE 的容器反向推会溢出）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `bars[].at` | `f(tWord(i,'一千')) − 镜头 from` | 对准**数字词**的起点，不是类别词（「二零二五年」）——柱子要和数字一起到；旁白先念年份再念数字且间隔 > 0.8s 时，宁可对类别词，别让画面空等 |
| `bars[]` 顺序 | 阵列顺序 = 左→右（横式：上→下） | 登场顺序由 `at` 决定，可以不照排列顺序（先讲今年再回头讲去年也行）；同一个 `at` 的两根一起长、互不降权 |
| `growFrames` | 22 | 项与项间隔 < 1s 时缩到 16；> 30 会变成进度条，和词脱节。下一项的 `at` 最好 ≥ 上一项 `at + growFrames`，否则上一根还在长就被降权 |
| `max` | 不传：自动取整齐上限，最高柱约占 80–88%（demo：2,015 → 轴 2,400，格线 800 / 1,600 / 2,400） | 同一片里多张图要共用刻度时才手动传；传得比最大值小会被抬到最大值。直式柱顶上方留了 170px，就算柱高 100% 数值也不会撞标题 |
| 格线 | 自动 2–3 条（手动 `max` 时 2–4 条），10% 不透明度；轴数字 26px / 45% | 手动 `max` 请传能被 2、3 或 4 整除成整齐数的值（150、2,400），否则退成 2 等分、轴数字可能带小数 |
| `unit` / `decimals` | `'人'`、0；百分比 `'%'`、1 | 单位 1–2 字；长单位写进 `title`（「報名人數（人）」） |
| `display` | `'約 12.4 萬'` | 取字串里第一段数字来滚动，其余当静态前后缀；写法要能被还原（`12.4`、`1,180`），像 `007` 这种还原不了的就整串静态显示。给了 `display` 就不挂 `unit` |
| `orientation` | `'vertical'` | 类别名 > 6 个全形字就换 `'horizontal'`：类别名在柱上方、可用整行宽度，数值跟在柱尾 |
| `title` / `titleAt` | 60px / 800，左上；`titleAt = 0` | 标题是这一镜「开场的承载」：第一个词锚 > 1.5s 才到时，标题 + 骨架先在场就不算空画布等词 |
| `note` | `'資料來源：官方統計'`，26px / 50%，y≈1352 左下 | 自绘图表必须有来源行；一行放不下直接截断，别写长句 |
| 降权 / 落定常数 | `DIM_TO .45`、`REST_TO .55`、`DIM_FRAMES 10`、`SETTLE_GAP 10`、`SETTLE_FRAMES 12` | DIM_TO < 0.35 旧柱读不到、失去参照；REST_TO > 0.7 重点柱跳不出来 |
| 版面（直式） | 柱区 x 176–900、y 470–1170；轴数字栏 x 60–160；柱宽 = 槽宽 ×0.6（≤180）、槽宽 ≤300 且整组置中；类别名 40px、柱下 22px | 柱与标签不进 x>900（平台按钮区），只有格线延伸到 1020；左轴栏与右留白刚好对称，图的视觉中心落在 x≈540 |
| 柱顶圆角 | 12（只圆生长方向那一端的两个角） | 面板 28 的同族小号；进片随风格档圆角等比换，财经 6 → 约 3 |

## 声音
- 每根柱子起长（对各自的 `at`）：`ui/ui-tone-quick.mp3` 或 `ui/switch-tap.mp3`，音量 0.15。数字词此刻正在被念，宁可省掉也不要压词；三根都放时第三根可以换 `ui/ui-select-modern.mp3` 做出递进
- 想要「数上去」的质感：`counter/clock-knob-spin.mp3` 0.12，截到 `growFrames` 长度，只给重点那一根
- 落定换色（对 `settleAt`）：`ui/ui-confirm-tone.mp3` 或 `ui/ui-success-soft.mp3`，音量 0.22——这一记通常落在句尾气口，是全镜唯一建议保留的音效
- 口播片音量一律 ≤ 0.35；不要用 `riser/`、`impact/` 的大件，这张卡的能量是累积不是冲击（要冲击用 stat-punch）

## 已知坑
- **截断轴 = 说谎，所以没有这个开关**：柱状图用「长度」编码数量，轴不从 0 起，1,420 对 1,180 的 20% 差距可以被画成三倍高。`baselineZero` 的型别只有 `true`，传 `false` 过不了编译；差距太小看不出来时，正解是换说法（直接用 stat-punch 讲「成長 20%」），不是切轴。同理生长曲线不准换成 `outBack` / `spring`——过冲的那几帧柱子比真实值高
- **超过 4 根请换卡**：第 5 根起直接不画（`slice(0,4)`）。直式柱区只有 724px 宽，4 根时槽宽 181px、数值已缩到约 45px；再多，数字与类别名都会小到手机上读不了。口播一句话也讲不完 5 个数——拆成两镜，或改用截图类卡（marker-sweep）指原文图表
- **长类别名**：直式每槽只有约 160–280px。类别名先折两行，再缩字到下限 30px，还放不下就两行截断（出现「…」）。而且类别名字号全图统一取最小值——一个长名字会把所有名字拖小（测试时 4 根里一个 15 字的名字把全部压到下限）。超过 6 个全形字就用 `orientation: 'horizontal'`，或回稿子里改短
- **`display` 会把数值字号拖小**：数值字号也是全图统一、按最宽的那个标签算。4 根时「約 12.4 萬」这种带前后缀的写法会把全部数值压到约 32px；`display` 尽量只留数字 + 1 字单位，「約」放进标题或旁白
- **不要混单位**：一张图一条轴一种单位。「人数」和「成长率」放在一起，柱高之间的比较没有意义；用了 `display: '12.4 萬'` 时 `value` 也请传 12.4（不是 124000），否则轴数字是 150,000、柱顶却写 15.0 萬，观众会对不上
- **每个数字都必须在 `sources/facts.md` 里有出处**：这是自绘图表，没有截图替你背书。`value`、`display`、`note` 逐项对 facts.md（终检项）；文章只给了成长率没给绝对值时，不准自己反推数字来画柱子
- 滚动早段位数较少时，数字靠右、左边的格子空着（1,180 在前 10 帧显示成「 925」），看起来略偏右——这是定宽格的代价，换来的是全程不横向抖；不要改成置中重排
- 轴数字栏只有 100px：超过 7 个字符（1,000,000 以上）会自动缩字到很小。大数请换算成「萬 / 億」传入（`value: 124.5, decimals: 1, unit: '萬'`），`value × 10^decimals` 也要在 2^53 以内
- 不支援负值（负数当 0 画）；涨跌对比请另选卡，别硬塞
- 不要用 `toLocaleString`：渲染机 locale 不同分隔符会变，卡内千分位是整数运算自己排的；换字体后 `DIGIT_EM = 0.6` 要重看（窄体数字约 0.52）
- 词锚距镜尾要留够：最后一个 `at` 之后还需要 `growFrames + 10 + 12` = 44 帧才换完色，再加至少 1s 读图——最后一个词锚距镜尾 < 2.5s 就把镜头尾巴拉长，或把换色留给下一句的气口（目前 `settleAt` 不可传，要改请改 `SETTLE_GAP`）

## 参考实现
demos/narration/bar-grow-compare/BarGrowCompare.tsx（`BarGrowCompareShot` 是镜头本体，不含 NarrationStage；demo 三根柱，词锚 24 / 66 / 108，帧 140 起换色）

成片接法：
```tsx
// timeline.ts 给出本镜 from / duration；tWord 来自 timing.ts。数字逐项抄自 sources/facts.md
const at = (line: number, word: string) => f(tWord(line, word)) - shot.from;
<Sequence from={shot.from} durationInFrames={shot.duration}>
  <BarGrowCompareShot
    title="近三年報名人數" unit="人" note="資料來源：官方統計"
    bars={[
      { label: '2024', value: 1180, at: at(4, '一千一百') },
      { label: '2025', value: 1420, at: at(4, '一千四百') },
      { label: '2026', value: 2015, at: at(5, '兩千'), highlight: true },
    ]}
    duration={shot.duration}
  />
</Sequence>
```
- 时间点：每根柱一个词锚（骨架里用 `atIn(shotId, line, '词')`），取该项**数字词**的起点；`titleAt` 通常留 0。`growFrames`、降权、落定都是相对量，不用换算
- 素材：不吃 `boxes.json` / manifest——这张卡是 `material.mode = chart` 的自绘图，唯一的「素材」是 `sources/facts.md` 里的数字与出处（出处写进 `note`）。要展示原文里现成的图表，请用截图类卡（marker-sweep / loupe-peek）
- 分镜检核：纯动效镜，计入「纯动效镜 ≤ 1/3」的额度；同屏主体 = 柱数（≤ 4，其中只有 1 根是当下主角，其余降权，符合第 3 条）
- 蒙皮：`N.accent` → `theme.accent`（重点柱 / 标题短线），`N.onDark` → `theme.ink`，`N.bg` / `N.font` 整组换 token；亮底风格档（旅游 / 生活）下 `onDark` 换成深色 ink 即可，降权靠不透明度、不靠颜色，不用另调。不改曲线、时序常数与格宽比例
