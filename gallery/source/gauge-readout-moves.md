## 意图
把"报数值"做成仪表的身体动作：A 是汽车点火自检——表盘指针先"唰"地
甩满全弧（270°）再回落定格真实值，多表错峰成波浪，先亮量程再报数，
开场宣誓感；B 是看盘 App 的语法——金色折线从左往右画出，线头跟着读数走、
价格标黏在线头，纵轴随已画出的最高值自动放大：慢爬段先被放大看清，冲刺段一来
整张图被撑开、斜率一眼可读，甩过头再回摆落定。观众最熟悉「走势线」，所以最快读懂
「先缓后急」。与 odometer-digit-roll 分工：那是数字在窗里滚，B 是把整段过程画成一条线。
（2026-09 改版：B 原为 tape-scroll-fixed-pointer 滚带定针，读起来像仪器；使用者从
「水平刻度带 / 走势线＋价格标 / 环形仪表 / 滚轮数字」四案里选了走势线＋价格标。）

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A needle-sweep-selftest | 指针去程 ~12f ease-out 甩满弧，回程 ~20f 带 5–8° 过冲回摆落真值；多表错峰 3–5f；落定同帧盘下数值弹出 | dashboard 开场/系统就绪仪式 |
| B trend-price-tag | 折线按帧画出（读数时间线：静置→慢爬→inOutCubic 冲刺过冲→回摆→落定）；线头金点 + 光晕、金色价格标 + 虚线拉到右缘；纵轴上限 = 已画最高值 + 高低差 15%；上方大字读数 + 涨跌幅 | 单指标大跳变：汇率 / 股价 / 币价急涨、性能翻倍 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 甩弧幅度 | 满量程 270° | 只甩到真值=没有自检仪式感；满弧再回落才是"先亮量程" |
| A 过冲 | 回落带 5–8° 回摆 | 无过冲读作电子表；过冲=机械指针的质量 |
| A 错峰 | 3–5f/表 | 齐甩读作复制粘贴；错峰成波浪 |
| B 冲刺 | 23f inOutCubic 冲到过冲值 | 太慢读作匀速爬升，看不出「急」 |
| B 回摆 | 过冲约 5% 再回落 | 直停像画好的静态图；回摆是「真的在跳动」的来源 |
| 真静止 | 停位后 ≥30f 全锁死 | 指针类最忌尾漂 |
