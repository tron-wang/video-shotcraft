## 意图
行情镜头要讲的是"价格走到了这里"，而 K 线图天然是一段历史。整张图直接淡入，观众
看到的是一张静态图表；逐根生长把历史变成过程，而**最新价标签始终咬住正在生长的那一根**，
把视线一路带到最后那个数字上。

铺满之后整段历史一起变窄是第二个关键：新蜡烛不是把旧的挤出画面，而是把过去压缩——
观众读到的是"时间在往前走、历史在变远"，比横向平移的滚动视窗更有纵深。

## 动效核心
- **揭示进度**：`count = (N + 2.5) × bezier(.55, 0, .3, 1)(t)`；第 i 根的生长
  `g = easeOutCubic(clamp((count − i) / 2.5))`。生长时长以"根"为单位：揭示慢时单根
  长得慢、快时一闪而过，全程节奏自洽
- **单根生长**：`cur = o + (c − o)·g`，实体画 `[min(o, cur), max(o, cur)]`；影线上端
  `max(o, cur) + (h − max(o, cur))·g`、下端对称；透明度 `min(1, 3g)`。颜色按最终涨跌
  定，生长途中不翻色
- **槽位宽**：`slotW = plotW / max(plotW / 34, min(N, count))`。count 取连续值，
  压缩是平滑的，不按根数一格一格跳
- **y 轴自适应**：原始区间 = 已出现蜡烛的 `[min(l), max(h)]`，上下各留 12%，跨度
  不小于 12；再对最近 8 帧的原始区间做三角加权平均（`w = 8 − k`）。每帧都能由帧号
  直接回算，不需要跨帧状态
- **刻度步长按最终区间定死**（10）：刻度线跟着重标上下滑、贴近绘图区边缘 30px 内淡出。
  中途不换步长，避免刻度标签跳档
- **最新价**：latest = 最后一根 g>0 的蜡烛，价格 = 它的 cur。右轴标签（52px 高、
  32px 数字）+ 从蜡烛右侧拉到轴的虚线，颜色按"cur 相对开盘"实时判涨跌；标题大数字
  与涨跌幅同步走
- 揭示完成后 f166 标签外框 20f 放大淡出一次
- 数据：确定性种子伪随机（mulberry32 + Box-Muller）三段行情——缓涨 34 根、回撤 18 根、
  主升 44 根

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 蜡烛数 N | 96 | <50 压缩阶段太短，看不出"历史变窄"；>200 单根 <8px，实体生长读不出来 |
| 槽位上限 | 34px，实体占 60% | 不设上限时前几根被撑成巨柱；>48px 前段像柱状图 |
| 揭示时长 / 曲线 | 150f，bezier(.55,0,.3,1) | linear 读作机械扫描（R2）；前段过慢（>2s 只有几根）观众不知道在等什么 |
| 单根生长 | 2.5 根 | <1 读作逐根闪现；>5 同时挂着一大片半截蜡烛 |
| 区间留白 | 12% | <6% 新高蜡烛在轴跟上之前顶出绘图区；>20% 曲线缩成中间一条 |
| 平滑窗口 | 8f 三角加权 | 0 = 新极值出现当帧轴跳变；>16f 新高蜡烛明显冲出上边界 |
| 最小跨度 | 12（价格单位） | 起手一两根时防止 1% 波动被放大成满屏大柱 |
| 行情形态 | 缓涨 → 回撤 → 主升 | 单边上涨没有张力；结尾回撤会让最新价标签停在跌色 |
| 涨跌色 | 涨绿跌红 | 面向中国大陆观众换成涨红跌绿 |

## 已知坑
- 行情是占位数据：换种子前先整段渲一遍看形态，随机序列不一定有想要的"回撤后新高"。
  真实产品片按 Q1 数据口径处理，公开行情也要确认可用授权
- 平滑窗口越大，新高蜡烛冲出上边界越明显；demo 用 12% 留白吸收 8f 的滞后。改窗口时
  同步检查主升段最后几根
- 刻度标签是纹理（26px、暗色），不是要读的文字；要读的只有标题价格和最新价标签（Q11）
- 实体高度设最小 2px：十字星（开盘 ≈ 收盘）没有最小高度，压缩后会完全消失
- 最新价标签会盖住附近的刻度标签——标签画在刻度之后直接覆盖，这是交易终端的常规做法，
  不要为了避让去挪刻度
- 用 SVG 不用 Canvas：百根量级 × 2 个元素 SVG 足够，文字和圆角更清晰；上千根
  （多年日线）再换 Canvas
- 涨跌色是市场惯例，不是审美选择：搞反会被读成下跌行情
