## 意图
展示「一组东西」时，最怕观众只看到一张。跑马灯一次铺满三排、十几张，相邻两排反向滑动让画面有来回的张力，整体微倾避免像表格；两侧渐隐让卡从虚无中滑进、滑出，没有「边界」。它没有开头也没有结尾，天然适合当衬底或循环素材。
（2026-09 改版：旧版 8 张紫色渐层卡排成圆环自转；使用者从「金边环形 / 双向跑马灯 / 弧形画廊 / 斜向无限墙」里选了双向跑马灯；卡名沿用。）

## 动效核心
- 三排（`rows`）卡片，每排从 `items` 依序重复铺满；排与排错开 3 张起始，避免上下同图对齐
- 整体 `rotate(−8°)`（`tilt`），水平方向 `mask-image` 两侧各 18% 渐隐
- 相邻两排反向横移：偶数排往左、奇数排往右，位移 = `frame × speed`，对「一轮长度」（`items` 数 × (卡宽 + 间距)）取模——一轮后回到原位
- 无缝循环：给 `loopFrames` 时速度自动取「`loopFrames` 帧刚好走完一轮」，末帧与首帧完全相同（已实测差值 0）
- 卡：360×280、圆角 18、1.5px 淡金描边、`0 20px 50px` 投影；以短边 1080 为准等比，横式直式都能用（直式建议 `rows={5}`）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `items` | 6–12 张图（`public/` 路径字串）或 ReactNode | < 5 张重复太明显；照片色调差太多时整面墙会花 |
| `rows` | 横式 3 / 直式 5 | 直式只给 3 排会上下留大片空白 |
| `speed` | 3 px/帧 | 使用者看过的速度；> 6 读作「在跑」、抢前景 |
| `loopFrames` | 不给（不循环） | 需要循环时给；速度 = 一轮长度 ÷ loopFrames。8 张 × 388px ≈ 3100px，要维持约 3px/帧就给 ~1000 帧；短循环会很快 |
| `tilt` | −8° | 0° 像表格；< −14° 两端卡被裁太多 |
| `stroke` / `bg` | 淡金 / `#0b0c0f` | 换风格档时给 theme 的强调色（低透明度）与底色 |

## 已知坑
- **循环与速度互斥**：一轮长度是固定的，循环越短速度越快；5–6s 的短循环会快到 18px/帧。要慢又要循环，就把镜头拉长或减少 `items`
- **人脸照片**：一面墙十几张照片同时出现，路人正脸会被放大检视；新闻照片挑远景、物件、场景
- **署名**：照片来源不同时，来源条要列全（或只标「图片来源：多方」并在 CREDITS 列明）
- **与前景文字**：当衬底用时整面墙要压暗（外面叠 0.5–0.6 的深色幕），否则抢字
