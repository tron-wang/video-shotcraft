## 意图
静态纯色底放 5 秒会「死」；彩虹渐层轮换（本卡旧版）又太花、会跟前景抢。这张卡给背景一层**看得出在动、但眼睛不会被它拉走**的能量：四团光晕固定在一个超大层上，整层极缓地漂、转、放大，每团再各自走一段错相位移，外加一层「呼吸」起伏——画面一直在变，但没有任何一个时刻在「跳」。预设配色是黑底 + 金 / 琥珀，跟财经风格档同一套；换 `colors` 就能换品牌色。
（2026-09 改版：使用者先看了「流体光晕 / 颗粒渐层 / 网格聚光 / 流动色带」四案，再在流体光晕里比了四种黑金配置，选了「多层琥珀」；中途两次回馈——「太生硬」「变化太慢」——定下了下面的滑顺原则与运动幅度。）

## 动效核心
- **滑顺原则**（参考 Stripe / aurora 类背景）：只做小幅 transform；一个镜头只走**半个来回**，用 `easeInOutSine` 头尾放缓——不等速、不循环跳回；颗粒是静态的，不逐帧换
- **整层**（`inset: -25%` 的超大层）：位移 ±5% / ±4%、旋转 −10° → +10°、缩放 1 → 1.14
- **各团光晕**：在半个来回里各走 9–12% 的错向位移；外加「呼吸」= 整段一个完整正弦周期 × 半个正弦包络（首尾近静止、中段多一点摆动），各团相位错开
- **光晕**：`radial-gradient(circle, 颜色 0%, transparent 70%)` 圆斑，直径按画面**短边**算（横式画幅不会盖满整个画面吃掉黑底）；整层 `blur(110px)` + `saturate(1.1)`，每团 `mix-blend-mode: screen`
- **颗粒**：`feTurbulence` fractalNoise 0.8 / 3 octaves、去饱和，overlay 0.14——只用来消掉深色渐层的色阶断层
- 预设四色：主光金 `rgba(224,176,75,.6)`、中调琥珀 `rgba(196,140,50,.55)`、深调暗琥珀 `rgba(120,84,30,.6)`、高光浅金 `rgba(240,205,130,.25)`；底 `#0b0c0f`

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| `intensity` | 1 | 运动幅度倍率。0.5 更安静（前景是长段文字时）、1.5 更活泼；> 1.6 会开始抢前景 |
| `duration` | 本镜长度 | 半个来回走完的帧数。镜头 > 10s 时给约 300，否则变化会慢到像静止 |
| `colors` | 黑金琥珀四色 | [主光, 中调, 深调, 高光]；换品牌色时保持「一亮一中一深一高光」的结构，alpha 就是亮度 |
| `bg` | `#0b0c0f` | 深底才撑得起光晕；浅底风格档改用 `colors` 里的低饱和色、`bg` 给米白，并把 screen 换成 multiply |
| `blur` | 110 | < 80 光斑边缘看得出圆形；> 140 整片糊成一色 |
| `grain` | 0.14 | 0 关闭；深色大面积时建议保留，压缩后不出色阶 |

## 已知坑
- **生硬 = 太快或等速**：第一版 6 秒跑完一整圈、色带等速流动还会跳回起点、颗粒每 2 帧换一次——使用者直接回馈「太生硬」。只走半个来回、`easeInOutSine`、颗粒静态
- **太慢 = 幅度太小**：第二版幅度只有现在的约 40%，使用者回馈「变化太慢」。现在的幅度是定稿值，调整请用 `intensity`，不要改常量
- **压缩色阶**：深色渐层用预设 CRF 压缩会出现色带、看起来像在抖；看样片或导出时用较低 CRF（14–18），并保留颗粒
- **字的对比**：光晕会游走到字后面；前景放白字时确认最亮那团（主光）经过字时对比仍够，必要时 `intensity` 降到 0.7 或把前景放到光晕较少的一侧
- 这是背景卡：前景自己叠在 `children`，不要再在上面盖整片暗幕（会把光晕压成灰雾）
